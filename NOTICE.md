# Créditos e licenças de terceiros

Este mod distribui (no pacote de instalação `.zip` das *Releases*) e/ou depende dos seguintes componentes de terceiros. Todos os créditos aos seus autores.

## BepInEx
- Carregador de plugins para Unity.
- Repositório: https://github.com/BepInEx/BepInEx
- Licença: **LGPL-2.1**.

## XUnity.AutoTranslator (e XUnity.ResourceRedirector)
- Autor: **bbepis**.
- Motor de tradução em tempo de execução para jogos Unity.
- Repositório: https://github.com/bbepis/XUnity.AutoTranslator
- Consulte o repositório para os termos de licença e a seção "Regarding Redistribution".

## Pixelify Sans
- Fonte pixel usada como *fallback* para renderizar caracteres acentuados.
- Licença: **SIL Open Font License 1.1 (OFL)**.
- Origem: Google Fonts — https://fonts.google.com/specimen/Pixelify+Sans
- A OFL permite redistribuição junto com software. O arquivo `PixelifySans.ttf` é incluído no pacote de instalação.

## Database Detective
- Jogo de propriedade da **HsuCorp**.
- Este é um projeto de tradução feito por fãs, **não-oficial** e **sem afiliação**.
- **Nenhum arquivo do jogo** (DLLs, assets, executáveis) é redistribuído neste repositório ou no pacote de instalação. O mod apenas adiciona arquivos ao lado dos do jogo, sem modificá-los.
